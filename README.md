# Customer Churn Prediction Pipeline

End-to-end Machine Learning pipeline designed to predict customer attrition using classification models.

## Key Deliverables

- Automated data preprocessing and feature scaling.
- Multi-model comparison using Random Forest and Scikit-Learn.
- Performance metrics logging (Precision, Recall, ROC-AUC).

## Getting Started

```bash
pip install -r requirements.txt
python main.py
```

## Tech Stack

Python, Scikit-Learn, Pandas, NumPy, Joblib.
